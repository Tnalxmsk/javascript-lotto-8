# javascript-lotto-precourse

# 기능 목록

## Entity

### 로또

- 로또 번호를 반환한다.
- 검증한다.
  - 1부터 45사이의 숫자로 구성되어 있는지 검증한다.
  - 중복되지 않는지 검증한다.
  - 6개의 번호를 입력했는지 검증한다.

### 당첨 로또

- 일치 개수를 계산한다.
- 보너스 일치 여부를 판단한다.
- 검증한다.
  - 숫자 값인지 검증한다. 
  - 1부터 45 사이의 숫자를 입력했는지 검증한다.
  - 당첨 번호와 중복되는지 검증한다.

### 주문

- 주문 금액과 구매 정보를 제공한다.
- 검증한다.
    - 숫자가 입력되었는지 확인한다.
    - 1000원 이상 1,000,000이하의 금액을 입력했는지 확인한다.
    - 1000원 단위인지 확인한다.

### 티켓

- 로또 구매 내역을 반환한다.
- 지불 금액을 반환한다.

## Service

### 발매기

- 금액만큼 로또를 발행한다.
- 로또를 생성한다.

### 판정

- 당첨 로또와 비교하여 등수를 판정한다.
- 각 등수별 개수를 집계한다.

### 수익 계산

- 구입 금액과 당첨 금액을 기반으로 수익률을 반환한다.
- 총 수익을 계산한다.
- 수익률을 계산한다.

### 통계

- 등수별 분포와 총 수익률을 제공한다.

## useCase

### 로또 구매 유즈 케이스

- 로또를 구매한다.

### 주문 결과 확인 유즈케이스

- 주문 결과를 확인한다.

### 당첨 로또 등록 유즈 케이스

- 당첨 로또를 등록한다.

### 주문 통계 조회 유즈케이스

- 주문 통계를 조회한다.

## ui

### 입력

- 금액을 입력 받는다.
- 당첨 번호를 입력 받는다.
- 보너스 번호를 입력 받는다.

### 출력

- 로또 구매 내역을 출력한다.
- 당첨 통계를 출력한다.
- 수익률을 출력한다.

## controller

### AppController

- 앱을 실행한다.

## utils

### 검증

- 공통 기능
    - 빈 값인지 확인한다.
    - 공백이 포함되었는지 확인한다.
- 당첨 번호를 검증한다.
    - 올바른 구분자를 입력했는지 검증한다.
